# JS-01 — Informe de pedidos

## Descripción

Programa desarrollado en JavaScript que genera un informe de pedidos, diferenciando los pedidos pagados de los pendientes de pago.

## Funcionamiento

El programa procesa una lista de pedidos y muestra en la consola:

- Número total de pedidos.
- Cantidad de pedidos pagados y pendientes.
- Importe total de los pedidos.
- Importe correspondiente a los pedidos pagados y pendientes.
- Referencias de los pedidos agrupadas según su estado.

## Ejecución

Es necesario tener instalado **Node.js**.

Desde la terminal, situarse en la carpeta del proyecto y ejecutar:

`node js-01-informe-pedidos.js`

## Tecnologías

- JavaScript
- Node.js para ejecutar el programa
- Git y GitHub para el control de versiones
